# AlterNative Casio — PWA для iPhone Duo

Третья самостоятельная реализация калькулятора в репозитории `alter-native-percent`.

## Запуск

https://shrekerianez.github.io/alter-native-percent/casio/

Откройте Safari → Поделиться → На экран «Домой».

## Возможности

- Клавиатура классического настольного калькулятора и ЖК-дисплей.
- Раскрытый режим: история, проценты, сохранённые числа и обратный расчёт.
- Компактный режим: калькулятор и история в диалоговом окне.
- Кнопки AC, CE, %, ±, ÷, ×, −, +, =, память MC/MR/M+/M−.
- Локальное сохранение, офлайн-работа, поддержка тёмного режима.

Интерфейс вдохновлён классическими калькуляторами и не связан с компанией Casio.
